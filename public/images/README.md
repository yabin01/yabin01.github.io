# 图片文件夹

文章里要用的图片，全部放到这个目录下。

## 两种加图方式

**方式一：在写作台直接上传（推荐）**

访问 `/write`，正文框下方有「图片」区：

1. 把图片**拖进去**，或点「＋ 上传图片」选文件；截图后也可以直接
   <kbd>Ctrl</kbd>+<kbd>V</kbd> 粘贴到正文框。
2. 图片会自动提交到仓库 `public/images/<子目录>/`，并在正文光标处
   插入好引用，不用手写路径。
3. 「子目录」留空时会自动跟随文章的「文件标识」。

**方式二：手动放进这个文件夹**

把图片复制到 `public/images/` 下的某个子目录，然后在文章里手写引用。
这样图片要等你在命令行提交、推送之后才会生效 —— 写作台不会替你
提交手动放进来的图片。

## 怎么在文章里引用

Markdown 语法，路径**以 `/images/` 开头**：

```markdown
![图表说明](/images/文件名.png)
```

方括号里是图片说明（鼠标悬停时显示，也是给搜索引擎和读屏软件看的），
圆括号里是路径。写好后图片会自动居中、限宽、圆角，和站内排版一致。

## 为什么用 `/images/` 而不是相对路径

本站根目录就是 `public/`，所以：

| 文件实际位置 | 文章里写的路径 |
| --- | --- |
| `public/images/eth-01.png` | `/images/eth-01.png` |
| `public/images/chanlun/01.png` | `/images/chanlun/01.png` |

以 `/` 开头表示从网站根目录算起，**文章放在哪个分类下都不用改**，
也不会因为移动文章导致图片失效。

## 命名建议

- **用英文、数字、连字符**，不要用空格和中文。
  中文和空格在网址里会被转义成一长串 `%E5%9B%BE...`，容易出错。
- **按文章建子目录**，图片多了才不会乱：

  ```
  public/images/
    ├── chan-lun-zhongshu/
    │     ├── 01.png
    │     └── 02.png
    ├── ethusdt-0810/
    │     └── 01.png
    └── shiji-taishigong/
          └── 01.png
  ```

  引用时写成 `![说明](/images/chan-lun-zhongshu/01.png)`。
- 建议按出现顺序编号：`01.png`、`02.png`……以后补图不用改名。

## 支持哪些格式

`png`、`jpg`、`webp`、`gif`、`svg` 都可以。

截图建议存成 `png`（文字清晰）；行情截图存成 `jpg` 或 `webp`（体积小）。

## 提醒

- 图片文件名一旦被文章引用，**不要再改名**，否则文章里会显示成裂图。
- 如果某张图体积特别大（比如超过 1 MB），页面加载会变慢，可以先压缩再放进来。
